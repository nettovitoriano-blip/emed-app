  1. Adjust the Window setting of the image to [20] by simultaneously holding the center mouse button down while dragging the cursor to the left. Adjust level for a viewable image as shown in Illustration 2.

  2. Position the reference ROI Box built in step 2 on the Plexiglas portion of the QA#2 phantom image without touching the water portion or the hole pattern. See Illustration 2.

  3. Type prop a in the Image Works Accelerator Line followed by <Return> to propagate Box # 1 ROI (size and position) on the remaining images in the series.

  4. Click on the [MEASURE] button and select the box ROI icon to display Box # 2. The system places an ROI box labeled # 2 at the center of the image with the exact same dimensions as Box # 1.

  5. Reposition Box # 2 over the water portion of the QA#1 phantom image and directly above Box # 1 (Box # 2 position in Illustration 2).

  6. Type prop a in the Image Works Accelerator Line followed by <Return> to propagate Box # 2 ROI (size and position) on the remaining images.

  7. Record the Mean values of the 1st, 3rd, 5th, and 7th images in the series for each of the two box positions in Table 2.
