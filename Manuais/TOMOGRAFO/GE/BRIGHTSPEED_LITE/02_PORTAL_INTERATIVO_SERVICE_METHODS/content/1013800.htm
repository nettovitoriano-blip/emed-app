Equipment Service - Table (Mechanical)

TOUCH SENSOR (JUMPER) SERVICE JUMPER

During service, the table touch sensors must remain operable for the table to fully function. To operate the table with the side covers removed, the sensors must be jumpered with dummy Touch Sensor connector, that is provided within Table ship collector.
