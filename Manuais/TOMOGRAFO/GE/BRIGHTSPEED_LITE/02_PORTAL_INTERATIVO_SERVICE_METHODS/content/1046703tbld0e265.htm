Table 2:  xw8400 Front Panel Power LED and Beep Code

Power LED and Sound ActivityDiagnosis and Service Action
NonePower supply failure
  1. Press the power button.
  2. If HDD LED = GREEN, replace the Host PC.
  3. If the HDD LED does not illuminate:
    1. Verify that the unit is plugged into a working AC outlet.
    2. Open the access panel and verify that the power button harness is properly connected to the inline front panel I/O device assembly connector.
    3. Verify that the power supply cables are properly connected to the system board.
    4. Verify power supply functionality.
Blinks red 2 times, once per second, then 2 second pause, 2 beepsThermal shutdown
  1. Ensure that the Host PC air vents are not blocked and the cooling fan is running.
  2. Open the access panel, press the power button, and see if the processor fan spins. If the processor fan is not spinning, make sure the fan cable is plugged onto the system board header. Ensure that the fan is fully/properly seated or installed.
  3. If the fan is plugged in and seated properly, but not spinning, check the processor fan.
  4. Verify that the fan assembly is properly attached.
  5. If problems persist, check the processor heatsink.
  6. Replace the Host PC.
Blinks red 3 times, once per second, then 2-second pause, 3 beepsCPU not installed
  1. Ensure that the processor is present.
  2. Replace the Host PC.
Blinks red 4 times, once per second, then 2 second pause, 4 beepsPower supply failure
  1. Open the access panel and ensure the following connections are secure on the system board:
    • 24-pin main power
    • 8-pin CPU
    • 4-pin memory
  2. Locate the faulty device by removing all devices and reinstalling them one at a time until the Host PC fails.
  3. Replace the Host PC.
  4. Verify power supply functionality.
Blinks red 5 times, once per second, then 2 second pause, 5 beepsPre-video memory error
  1. Reseat DDR2 memory DIMMs.
  2. Replace the Host PC.
Blinks red 6 times, once per second, then 2 second pause, 6 beepsPre-video graphics card error.

For systems with graphics cards, do the following:

  1. Reseat the graphics card.
  2. Replace the Host PC.
Blinks red 7 times, once per second, then 2 second pause, 7 beeps.System board failure (ROM detected failure before video).
  1. Clear CMOS.
  2. Flash the BIOS and restore settings.
  3. Replace the Host PC.
Blinks red 8 times, once per second, then 2 second pause, 8 beepsInvalid ROM based on bad checksum
  1. Clear CMOS.
  2. Flash the BIOS and restore settings.
  3. Replace the Host PC.
Blinks red 9 times, once per second, then 2 second pause, 9 beepsSystem power is on but unable to boot.

Replace the Host PC.
