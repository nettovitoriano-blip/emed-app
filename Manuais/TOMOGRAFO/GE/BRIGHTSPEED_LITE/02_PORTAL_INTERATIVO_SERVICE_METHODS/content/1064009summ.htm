HP Host Computer CDIP Board Installation

(Click Here to Return to Detailed Procedure)

  Safety

NOTICE
To prevent damage to components within the HP xw8x00 chassis, observe the following ESD precautions:

  • Work on a static-free mat.

  • Wear a static strap to ensure that any accumulated electrostatic charge is discharged from your body to ground.

  • Create a common ground for the equipment you are working on by connecting the static-free mat, static strap and peripheral units to that piece of equipment.

 

1  Procedure

1.1   Remove the Side Cover

In All-in-One console, CDIP board is installed in HP Host Computer, and not included in FRU of Host Computer. Before HP Host Computer replacement, need to remove the CDIP board in old Host Computer and install it in new Host Computer at first.With ALL cables removed from the old and new Host Computers, perform the following steps:

  1. Unlock the cover on the side of the old Host Computer.

    (Step Details)

  1. Pull out on the side cover latch to release the side cover.

  1. Tilt the cover open, then lift it off. Refer to Illustration 1.

    (Step Details)

  1. Repeat the above procedure, to open the new Host Computer.

1.2   Installing CDIP Board

  1. Locate CDIP board in Host Computer (slot 5).

  1. Remove CDIP Board from the old computer and install it in the appropriate slot position (slot 5) in the new Host Computer.

1.3   Replace the Side Cover

  1. Ensure that all internal cables are properly connected and safely routed in the new Host Computer.

  1. Place the side cover onto the Host Computer chassis (aligning the guide rail on the bottom inside edge of the cover with the bottom edge of the Host Computer chassis). Refer to Illustration 2.

    (Step Details)

  1. Verify no cables are pinched, and gently close the cover.

  1. Lock the cover using the key provided.

  1. Repeat the above procedure, to close and lock the original Host Computer, with the new drives installed.

2  Finalization

  1. Continue with HP Host Computer Replacement (if applicable).
