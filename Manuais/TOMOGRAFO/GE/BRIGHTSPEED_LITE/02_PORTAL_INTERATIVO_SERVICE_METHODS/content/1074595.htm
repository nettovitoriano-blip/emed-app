4  Procedure

4.1  Phantom Setup

  1. Record the phantom serial number on GE e4879 Component Replacement Form.

  1. Perform Center Phantom.

  1. Set Internal Landmark.

4.2  Acquire Scans

  1. Select [NEW PATIENT] from bottom of Scan monitor.

  1. Type the following entries in the listed Patient Information fields:

    1. Patient ID: Service

    1. Patient Name: Quality Assurance Test

  1. Select Anatomical Selector Service tab from Protocol Selection.

  1. Select [MANUFACTURING], [IMGSER 20CMQA] from Anatomical Selector Service tab.

  1. Select [CONFIRM].

  1. Press [START] on SCIM / GSCB when it flashes. Scans are performed.

  1. Select [NEXT SERIES].

  1. Select [CONFIRM].

  1. Press [MOVE TO SCAN] on SCIM /GSCB if it flashes.

  1. Press [START] on SCIM / GSCB when it flashes. Scans are performed.

  1. Repeat Steps [7] - [10] until all series have been performed and completed.

  1. When all series are completed, select [END EXAM].

  1. If a PPS Response window is displayed, select [COMPLETE].

4.3  Analysis

  1. Select SERVICE desktop and move SERVICE desktop window to left monitor.

  1. Select IMAGE QUALITY tab from SERVICE desktop.

  1. Select IMAGE ANALYSIS and move IMAGE ANALYSIS window to left monitor.

  1. Select scanned examination from right monitor List/Select browser.

    NOTE:Series 1 and Image 1 should be selected. If not, select them.

  1. Press [AUTO 1X] radio button on IMAGE ANALYSIS window.

  1. Select [AUTO 1X] selection button, [IMGSER 20QA], and first test choice.

    NOTE:Number of test choices correspond to the number of series in the scanned examination. The order of the test choice correlates with the series number of the scanned examination (Series 1/Test 1, Series 2/Test 2, etc.).

  1. Select [ACCEPT].

    NOTE:At test completion, test data results, including specification limits and Pass/Fail results, are displayed.

    NOTE:At the top of the results window, the test Pass/Fail summary result is posted.

  1. Record results on GE e4879 Component Replacement Form.

  1. Click [DISMISS] from Report window.

  1. Select next series from right monitor List/Select browser.

  1. From IMAGE ANALYSIS window, select [AUTO 1X] selection button, and select [IMGSER 20QA] and next test choice.

    NOTE:If test choice has multiple selections, execute each selection.

  1. Select [ACCEPT].

    NOTE:If test requires user input, follow instructions in IMAGE ANALYSIS window lower right pane.

    NOTE:At test completion, test data results, including specification limits and Pass/Fail results, are displayed.

    NOTE:At the top of the results window, the test Pass/Fail summary result is posted.

  1. Record results on the GE e4879 Component Replacement Form.

  1. Click [DISMISS] from Report window.

  1. Repeat steps [10] - [14] until all tests have been performed.

  1. When all tests are completed, click [QUIT].

    NOTE:If any test fails, repeat failed test. If the test fails persistently, perform appropriate corrective action.

4.4  Image Review for Bands and Streaks

  1. From IMAGEWORKS desktop List/Select browser, select scanned examination, and Series 3.

  1. Select [VIEWER] and review all images from series for band and streak artifacts.

  1. If any images depict bands, perform steps in Band Analysis, Band Analysis, on those images.

  1. If any images depict streaks, perform Streak Test.

  1. In viewer, select series 5 and review all images from series for band and streak artifacts.

  1. If any images depict bands or streaks, repeat Step [3] or [4].

  1. Repeat Steps [5] - [6] for Series 7 and 10.

4.5  Band Analysis

  1. Select SERVICE desktop and move SERVICE desktop window to left monitor.

  1. Select IMAGE QUALITY tab from SERVICE desktop.

  1. Select [IMAGE ANALYSIS] and move IMAGE ANALYSIS window to left monitor.

  1. From the List/Select browser on right monitor, select image to be analyzed.

  1. Press [MANUAL] radio button on the IMAGE ANALYSIS window.

  1. Click [MANUAL] selection button, then [BAND].

  1. Click [ACCEPT]. The image is displayed in IMAGE ANALYSIS window with a Band ROI.

  1. Follow instructions, in IMAGE ANALYSIS window lower right pane, to size Band ROI and analyze.

  1. From results, if Avg. Ref. Band Factor is out of specification range of +/-2.8, perform appropriate corrective action.

  1. When all tests are completed, click [QUIT].

5  Finalization

Store the GE e4879 Component Replacement Form with system history records. The results are stored in a text file on the scanner and can be retrieved at /usr/g/service/state/image_analysis.log.
