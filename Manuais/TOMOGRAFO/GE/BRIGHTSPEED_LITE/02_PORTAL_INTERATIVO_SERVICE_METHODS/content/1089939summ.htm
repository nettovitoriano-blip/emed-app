Intercom Board Replacement (True-In-One Console)

(Click Here to Return to Detailed Procedure)

  Safety

NOTICE
All cable connector screw-locks must be finger-tightened, only. Do NOT use any tool to tighten cable screw-locks.
 

1  Procedure

1.1   Power-Off (Shut Down) the Console

  1. Select one of the following methods to Power OFF the Operator Console:

    1. If Applications are up, click on the [Shut Down] button and select [Shutdown].

      (Step Details)

    1. If Applications are down, open a Unix Shell. Type: halt.

  1. Power OFF the console at the front panel switch.

    Illustration 1:  Power Switch

1.2   Remove the Old Intercom Board

  1. Remove the Operator Console covers.

    (Step Details)

  1. Remove the four screws located on the front panel of Intercom Board, which secures Intercom Board to the chassis.

    (Step Details)

  1. Visually verify proper labeling of each cable and disconnect all cables on the panel. If necessary, add a label to each cable for clarity.

    (Step Details)

1.3   Install the New Intercom Board

  1. Slide the replacement Intercom Board into the Console.

  1. Re-Connect the cables as using Remove the Old Intercom Board, Step 3 above as a guide. At the rear panel of Intercom Board, verify the power switch is in the “ON” position, and connect the power cord.

    (Step Details)

1.4   Power On the Console

  1. Power [ON] the Operator Console.

1.5   Intercom Board Adjustment / Test

  1. Adjust the console and table speaker volume; refer to Intercom Adjustments

  1. Take some scans which need to do prescribed tilt; verify the prescribed tilt function is normal.

2  Finalization

  1. Install the console covers back.
