Table 3:  Z800 POST Error Messages

Screen MessageProbable CauseRecommended Action
101-Option ROM ErrorSystem ROM checksum
  1. Clear CMOS, flash the BIOS and restore BIOS Settings.
  2. May be ROMs on other expansion cards.
  3. Replace the Host PC.
102-System Board FailureDMA, timers
  1. Clear CMOS.
  2. Flash the BIOS and restore settings.
  3. Replace the Host PC.
 
110-Out of Memory for Option ROMs.Option ROM for a device was unable to run due to memory constraints.
  1. Clear CMOS.
  2. Flash the BIOS and restore settings.
  3. Replace the Host PC.
 
 
162-System Options Not SetYour system configuration has changed since your last boot, in which case press <F1>. Or, a loss of power to the Real Time clock (RTC) has occurred.
  1. Run Computer Setup (<F10> Setup).
  2. Set the date and time under <F10> Setup (depending on the operating system).
  3. If the problem persists, replace the RTC battery.
 
 
 
 
 
163-Time and Date Not SetInvalid time or date in configuration memory. RTC battery might need to be replaced. CMOS jumper might be improperly installed.
  1. Set the date and time under <F10> Setup.
  2. If the problem persists, replace the RTC battery.
 
 
 
164-Memory Size ErrorThe system memory size is different or memory configuration changed from the last startup.
  1. Press <F1> to record the configuration.
  2. If the problem persists, be sure memory modules (if any) are installed correctly.
  3. If third-party memory was added, use the HP to test the memory only.
  4. Verify proper memory module type.
 
 
 
 
201-Memory ErrorThe memory test performed during startup failed.
  1. Run Computer Setup (<F10> Setup).
  2. Ensure that memory modules are installed correctly.
  3. Verify proper memory module type.
  4. Remove and replace memory modules one at a time to isolate the faulty module.
  5. Replace the Host PC.
 
 
 
 
 
202-Memory type mismatchMemory modules do not match each other.Replace memory modules with matched sets. 
203-Memory module failedDefective memory moduleReplace DIMMs. 
204-Memory module failedImproper module loadReseat DIMMs. 
205-Memory high temperature detectedInsufficient memory module coolingVerify memory cooling fan. 
206-Memory set up invalidDIMMs does not match to system requirement.
  1. Reseat DIMMs.
  2. Replace DIMMs.
 
 
207-Incompatible memory modules detected.Incompatible memory module(s) detected.
  1. Verify proper memory module type.
  2. Try another memory socket.
  3. Replace the Host PC.
 
 
 
209-Memory warning conditionIncompatible memory modules detected.
  1. Verify proper memory module type.
  2. Replace the Host PC.
 
 
212-Failed ProcessorProcessor failed to initialize.
  1. Reseat the processor in its socket.
  2. If the processor does not respond, replace the Host PC.
 
 
213-Incompatible ECC Memory Module in memory Socket(s).The memory modules in the system are either not all ECC, or not all non-ECC. Another cause is the DIMM is missing critical SPD information.
  1. Verify proper memory module type.
  2. Replace the Host PC.
 
 
214-DIMM Configuration WarningDIMMs not installed correctly (not paired correctly).Refer to the Theory section for the correct memory configurations and reseat the DIMMs accordingly. 
301-Keyboard Error.Keyboard failure.
  1. Reconnect the keyboard with the workstation powered off.
  2. Check the connector for bent or missing pins.
  3. Replace the keyboard.
 
 
 
 
303-Keyboard Controller ErrorI/O board keyboard controller.
  1. Reconnect the keyboard with the workstation powered off.
    NOTE:Ensure that none of the keys are pressed.

  2. Replace the Host PC.
 
 
304-Keyboard or System Unit ErrorKeyboard failure.
  1. Reconnect the keyboard with the workstation powered off.
    NOTE:Ensure that none of the keys are pressed.

  2. Replace the keyboard.
  3. Replace the Host PC.
 
 
 
 
510-Splash Screen image corruptedSplash Screen image has errors
  1. Clear CMOS.
  2. Flash the BIOS and restore settings
 
511-CPU Fan not detectedFan is not connected or may have malfunctioned.
  1. Reseat the fan cable.
  2. Reseat fan.
  3. Replace Host PC.
 
 
 
512-Chassis fan not detectedFan is not connected or may have malfunctioned.
  1. Reseat the chassis or rear chassis fan cable.
  2. Reseat the chassis, rear chassis, or front chassis fan.
  3. Replace the Host PC.
 
 
 
513-Memory fan not detectedMemory fan is not connected or may have malfunctioned.
  1. Reseat the memory fan connector.
  2. Replace the Host PC.
 
 
514-Memory fan not detectedMemory fan is not connected or may have malfunctioned.
  1. Verify that the memory fan is installed properly.
  2. Replace the fan.
 
 
515-CPU Overtemp ocurredInsufficient processor cooling or processor defect.Replace the processor. 
516-Chipset fan not detectedChipset fan is not connected or may have malfunctioned.
  1. Ensure that the fan is installed properly.
  2. Replace the fan.
 
517-Low power CPU heatsink(s) detected for high power CPUsHeatsink is not installed correctly.Replace the Host PC. 
518-Power supply wattage insufficient for hardware configurationWorkstation requires more power than the power supply can provide.Replace the power supply. 
601-Diskette Controller ErrorDiskette controller circuitry or diskette drive circuitry incorrect.
  1. Run Computer Setup (<F10> Setup).
  2. Disconnect any other diskette controller devices (tape drives).
  3. Clear CMOS.
  4. Flash the BIOS and restore settings.
  5. Replace the Host PC.
 
 
 
 
605-Diskette Drive Type ErrorMismatch in drive type.
  1. Run Computer Setup (<F10> Setup).
  2. Disconnect any other diskette controller devices (tape drives).
  3. Clear CMOS.
  4. Flash the BIOS and restore settings.
.		 
 
 
610-External Storage Device FailureExternal drive not connected.
  1. Check the Peripheral Tower cable connection.
  2. Check the SCSI Adapter Card setup.
  3. Press <F1> and allow the system to reconfigure without the drive.
  4. Replace the Host PC.
 
 
 
 
 
 
611-Primary Diskette PortAddress assignment conflict
  1. Run Computer Setup (<F10> Setup).
  2. Check the cables.
  3. Clear CMOS.
  4. Flash BIOS and restore settings.
  5. Replace Host PC.
 
 
 
 
912-Computer Cover Has Been Removed Since Last System Start UpN/ANo action required. 
916-Power Button Not ConnectedPower button not connected.Connect the power button. 
917-Front Audio Not ConnectedFront audio cable not connected.Connect the front audio cable. 
918-Front USB Not ConnectedFront USB not connected.Connect the front USB cable. 
921-Device in PCI Express Slot Failed to InitializePCI Express card detected in one of the slots, but failed to initialize properly.Reseat all PCI Express cards.
NOTE:If this failure occurred after inserting a new card, there could be a problem with that card.

 
922-Fatal error on slot #Fatal error occurred in the designated slot.
  1. Reseat the card or move it to a different slot.
  2. If the problem persists, replace the Host PC.
 
923-Non fatal error on slot #PCI or PCIe non-fatal error condition occurred for the device in the designated slot.
  1. Reseat the card or move it to a different slot.
  2. If the problem persists, replace the Host PC.
 
1720 SMART Hard Drive Detect Imminent FailureHard drive is about to fail.
  1. Determine if the hard drive is giving the correct error message.
  2. Back up the contents and replace the Host PC.
 
 
 
1783-Disk 0/1 Failure.Drive not installed correctly or has failed.
  1. Ensure that power and drive cables are connected to the drive and to the system board.
  2. Verify that the cables are the correct cables for your computer model.
  3. If this message persists, replace the Host PC.
 
 
 
 
1801-Microcode Update ErrorMissing or Invalid Processor Microcode Update
  1. Contact HP for a new Microcode Update to support the new Processor Stepping.
  2. Upgrade the BIOS to the proper version.
 
 
1802-Processor Not SupportedSystem board does not support the processor.Replace the processor with a compatible one. 
Invalid Electronic Serial NumberElectronic serial number has become corrupted.
  1. Run Computer Setup.
  2. If Setup already has data in the field or does not allow you to enter the serial number, replace the Host PC.
  3. Run Computer Setup and try to enter the serial number under Security>System ID.
  4. Save the changes.
 
 
Network Server Mode Active and No Keyboard AttachedKeyboard not detected.Verify that a keyboard is attached.
