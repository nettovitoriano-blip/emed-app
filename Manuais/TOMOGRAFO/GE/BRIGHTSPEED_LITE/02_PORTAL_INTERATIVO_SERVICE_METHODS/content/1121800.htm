Service Pack 1.7 for 09BW35.11 Installation (only for service pack installation)

Last Revised:18 NOV 2010

1  Overview

This procedure applies to the systems with 09BW35.11 already installed.

2  Check System Configuration

NOTICE
The service pack should ONLY be loaded onto your CT-only True-In-One console with 09BW35.11 software.
 

NOTICE
Do not load this service pack on a PET/CT system.

Do not load this service pack on a non-TIO Operator Console.

 

Check system configuration by one of the following methods:

  1. Open a Unix Shell and type one of the following:

    check_config

    - OR -

    swhwinfo  -all

  2. Look at the Common Service Desktop Home Page.

3  Procedure

  1. Save System States.

  2. Remove all options on system

    NOTE:some options might not function well if options are not removed this time and restored back after SP1.7 installed.

  3. Open a Unix Shell.

  4. If Application software is up, perform the following command

    {ctuser@hostname}  cleanMon

  5. In the Unix Shell and become root:

    1. {ctuser@hostname}  su  -

    2. Password:<password>

  6. Check whether Service Pack is installed or not. Type [root@hostname]#swhwinfo

    1. If SP1-2-1 or SP1-4-1 included in the output, uninstall it using the instruction below first

      [root@hostname]#patch_install -u, the run step 7.

    2. If SP1-5-1 included or no information like SP X-X-X included in the output, move to step 7.

  7. Insert the Service Pack CD into DVD drive in the host.

  8. Perform the following steps to install SP1.3, SP1.5, SP1.7 orderly:

    1. [root@hostname]#patch_install -c

    2. Input y to install patch.

  9. Type: [root@hostname]#reboot

  10. After the application is up, restore system states

  11. Reboot system, after the system is up, perform Flash Download from Common Service Desktop.
