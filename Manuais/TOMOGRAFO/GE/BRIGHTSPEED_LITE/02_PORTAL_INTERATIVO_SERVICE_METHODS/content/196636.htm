1  HP Computer CD-ROM - Mount and Un-mount Process

1.1  Procedure

  1. Insert the CD into the HP Host Computer DVD-ROM drive.

  2. Open up a Unix Shell and type these commands:

    1. ctuser: su<space>-<ENTER>

    2. password: <password><ENTER>

    3. root: mount<space>/mnt/cdrom<ENTER>

      The CD mounts.

  3. To view the cd contents, type:

    ls<space>/mnt/cdrom<ENTER>

  4. Read a file from the LFC CD.

  5. To remove the cd from the drive, first un-mount it by typing:

    umount<space>/mnt/cdrom<ENTER>

1.2  Troubleshooting/Checks

  1. Refer to applicable HP Host Diagnostics procedure located in the Troubleshooting → Console folder.

  2. Replace the HP computer.

2  Peripheral Tower DVD - Mount and Un-mount Process

2.1  Procedure

  1. Insert the DVD into the Peripheral Tower DVD-RAM drive.

  2. Open up a Unix Shell and type: mountDVD<ENTER>.

    The DVD mounts.

  3. To view the contents of the DVD, type:

    ls<space>/DVD<ENTER>.

  4. Read a file from the operators CD or (save and restore a save state).

  5. To remove the DVD from the drive, first un-mount it by typing:

    unmountDVD<ENTER>.

2.2  Troubleshooting/Checks

  1. Check that the Terminator LED is ON.

  2. Swap the SCSI cable.

  3. Ensure the terminator is properly situated.

3  Peripheral Tower DVD - Initializing a DVD Media

If a DVD needs to be initialized on new media, open a Unix Shell and perform the following actions.

  1. Type: su<space>-<ENTER>

  2. Enter the root password: <password><ENTER>

  3. Type: mountDVD<ENTER>

  4. Type: mkfsDVD<ENTER>

  5. Answer y for yes and close the Unix shell.

4  Peripheral Tower MOD - Mount and Un-mount Process

4.1  Procedure

  1. Insert the MOD into the Peripheral Tower MOD drive.

  2. Open up a Unix Shell and type: mountMOD<ENTER>

    The MOD mounts.

  3. To view the contents of the MOD, type:

    ls<space>/MOD<ENTER>

  4. Save and read an image series.

  5. To remove the MOD from the drive, first unmount it by typing:

    unmountMOD<ENTER>

    NOTE: If the MOD cannot be unmounted, select: Image Works → Archive → Detach

4.2  Troubleshooting/Checks

Check that the Terminator LED is ON.
