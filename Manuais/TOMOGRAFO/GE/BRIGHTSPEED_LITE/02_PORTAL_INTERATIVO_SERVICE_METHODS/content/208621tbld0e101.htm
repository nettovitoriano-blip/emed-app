Table 1:  Synchronization Signal

SignalDescription
GantryThe gantry synchronization signal is activated when the gantry position register matches the gantry interrupt position register. The gantry sync signal is used for all rotating scans.
TableThe table synchronization signal is activated when the Table sync signal is received by the MSUB from the Table. The table sync signal is used for scout scans.
FirmwareThis signal is activated by firmware. This signal is used for static scans.
