Rotating Controller Interface Bus (RCIB)

Last Revised:11 June, 2003

1  Functional Overview

The Rotating Controller Interface Bus (RCIB) defines the communication for all the components in the rotating base of the CT gantry.

Each subsystem on the CT RCIB contains two physically identical connectors. The following components are interconnected via the CT RCIB:

  • Scan Control

  • JEDI Generator

  • ORP

  • Collimator

  • DAS & Detector

  • Slip Ring Interface

  • X-Ray Tube Smart ID

2  Signal Components

The CT RCIB consist of the following signals:

  • One controller Area Network Channel (CAN - 2 wires), per ISO/DIS 11898

  • One parallel real time signal: FAULT (2 wires), per ISO/DIS 11898

  • Four parallel real time signals: RESET, XRON, EXPXMD, and TRIGGER (8 wires), per modified RS485 protocol

  • One series Real Time signal: PSFB (1 wire), per Daisy-chain loop specification

  • +12 VDC and 12VRTN for optical isolation of the above signals (2 wires)
