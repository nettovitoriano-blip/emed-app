Required PersonsPreliminary ReqsProcedureFinalization

2  Overview

Run the Filament Calibration procedure. The Filament Calibration tool runs an automated scan sequence and populates the JEDI database accordingly.

Last Revised:June 2003

3  Procedure

  1. Launch the [GENERATOR TOOL] from the Service Desktop. See Software section for more details.

  1. Launch the Filament Calibration tool.

  1. Run the test.

  1. The software automatically warms up the tube and run the scans to calibrate the filament. If filament calibration fails, run the program again.

    NOTE:If Filament Calibration fails persistently, try downloading the default database to the PPC kV control board and running this procedure again.
