Converter Card RTS data

This document defines the available Real Time Statistics (RTS) data available on the system for the DAS converter cards. The RTS data is sent by the DCB to the host at the end of each exam.

The RTS viewer for the Converter Card temperatures shows a listing of Converter card temps. See Table 1 for an example of the data seen with expected ranges.

cnvbrdTemp:32.4Degree C15.0 - 65.0Temperature on converter board: DAS is specified to operate between 15 to 65 Degrees. If DAS temp goes above 65 Deg, converter boards will assert a fault which will prevent system from scanning until temp gets under 62 Deg C. If temp ever gets this high, system fans need to be serviced. Typical board temp is between 30-40 degrees.
