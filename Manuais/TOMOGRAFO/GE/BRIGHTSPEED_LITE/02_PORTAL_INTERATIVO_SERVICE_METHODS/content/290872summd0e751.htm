  1. Position the reference ROI Box built in step 2 directly over the center of the image using the grid cross-hairs as a guide.

  2. Type prop a in the Image Works Accelerator Line followed by <Return> to propagate Box # 1 ROI (size and position) on the remaining images in the series.

  3. Click on the [MEASURE] button and select the box ROI icon to display Box # 2. The system places an ROI box labeled # 2 at the center of the image with the exact same dimensions as Box # 1.

  4. Reposition Box # 2 to the left center portion on the first image.

  5. Type prop a in the Image Works Accelerator Line followed by <Return> to propagate Box # 2 ROI (size and position) on the remaining images.

  6. Record the Mean values of the eight images in the series for each of the five box positions in Table 4.

    Each image can only display text for the mean, standard deviation, and box area for three images at a time. To view the data for a particular box, select the box on the image and the system displays the data for the box number selected.
