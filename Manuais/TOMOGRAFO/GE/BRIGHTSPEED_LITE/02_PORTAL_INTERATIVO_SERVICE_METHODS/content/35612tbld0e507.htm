Table 3:  Steps for Starting a Snoop Session

STEPCOMMENT
1. Open up a Linux (or Unix) shellFrom Desktop, select Linux (or Unix) Shell
2. Become root.su -
3. Start the snoop session in the shell and set it up to display outgoing and incoming packets.snoop -SVta <camera ip address>
4. Send a DICOM Print job to the cameraIn ImageWorks desktop, display an image and drag/drop the image into the film composer and Print it.
5. Observe the output packets of data being sent and received.Length sizes < 500 = communication request between the scanner and the print server.

Length sizes ~1500 = the image packet size being sent.
