2  Overview

Direct Connect lets you use the AW to process images on the CT/PET console, without having to first pull them to the AW. Source images remain on the CT/PET console, while new post-processed images are saved to the AW.

Last Revised on:19 September 2008

Table 1:  Network/Connection Requirements

Direct Line Between AW and CT/PET ConsoleOver Hospital Backbone (not available for VCT M3A - 05MWxx.x):
  • RJ45 cables of category ≥ cat 5e must be used for 1GBPS connection.
  • The cable should be connected to the “AW/X” port on the back of the console.
  • If performing Direct Connect over the hospital backbone, no additional hardware or connection is required.
  • Hospital network must be a gigabit network to support Direct Connect. If hospital does not have a gigabit network, configuration will not be allowed, as Direct Connect performance will be adversely affected.

4  Procedure

4.1  Over Hospital Backbone Connection Setup

A gigabit network is required to use Direct Connect over the hospital backbone. If you believe the hospital backbone is a gigabit network but the software will not enable you to configure Direct Connect over the network, check to see if a < 1 GB switch is pulling down the network speed to the system.

4.1.1  Configuring an AW IP Address for Direct Connect

  1. With Applications software up, select the [Service] icon to access the Common Service Desktop.

  1. Select the [Configuration] tab.

  1. Select [Configure AW Direct Connect].

  1. Enter AW IP address.

    Illustration 1:  Configure AW DirectConnect On Network Screen

  1. Select [Accept].

  1. You will receive a message indicating that the AW IP address has been configured for Direct Connect. You will now be able to use Direct Connect with this AW.

    NOTE:Without a 1 GB switch (or greater), the configuration message will not be received.

  1. Select [Dismiss] to exit out of GUI.

4.1.2  Deleting an AW IP Address for Direct Connect

  1. Switch to the Service icon.

  1. Select the [Configuration] tab.

  1. Select [Configure AW Direct Connect].

  1. Enter AW IP address.

  1. Select [Delete].

  1. You may receive a message indicating that the AW IP address has been un-configured for Direct Connect.

  1. Select [Dismiss] to exit out of GUI.

    NOTE:For information on how to set-up the CT/PET console as a Direct Connect remote host on the AW4.3, please refer to the AW4.3 Service Manual (5136311-100), Installation Job Cards List-Job Card IST 002). When configuring the remote host, the field “IP used for Direct Connect” should be completed with the console’s network IP address. AW 4.3 Service Manual (5136311-100) may be accessed on the AW 4.3 by selecting AdminàService Docs and selecting the AW 4.3 Service Manual link.

4.2  Direct Line Connection Setup

Use this section for “Direct Line” connection setup.

4.2.1  Configuring the First AW for Direct Connect over a Direct Line

NOTE:For GOC6 Consoles: Before starting configuration, the AW Workstation network cable must be connected to the J29 on the Rear Bulkhead Panel of the GOC6 Console (xxx). For earlier GOC Operator Consoles, check the appropriate Installation Manuals for port location.

Illustration 2:  Rear Bulkhead Panel Connects

  1. Switch to the Service icon.

  1. Select the [Utilities] tab.

  1. Select [Application Shutdown].

  1. Open a Unix Shell.

  1. Login as root and enter the proper password:

    NOTE:If the Password has not been modified by the site and is not known, contact Local GE Service.

    1. su -

    1. Password:

  1. Type: reconfig

  1. Select [Config].

  1. Select the [Network] tab.

  1. Select [Enable AW Direct Connect?] button to configure the console for Direct Connect.

  1. Copy down the following information, as it will be required for the configuration of the AW:

      Console IP Address: 	_____________________
  AW IP Address:	_____________________
    NOTE:The AW IP Address above refers to the AW Direct Connect IP Address.

  1. Select [Accept].

  1. Upon restart, the console will be correctly configured for AW Direct Connect.

    NOTE:The CT/PET console assigns the AW a Direct Connect “AW IP Address” (which you copied down in Step 10). This IP address must be used to configure the AW for Direct Connect. If the AW4.3 has already been configured, you will need to re-configure it with the assigned IP address. Configuration of the AW for Direct Connect can be found in the AW4.3 Service Manual (5136311-100), Installation Job Cards List-Job Card IST 001. AW 4.3 Service Manual (5136311-100) may be accessed on the AW 4.3 by selecting AdminàService Docs and selecting the AW 4.3 Service Manual link.

4.2.2  Configuring Multiple AW’s for Direct Connect over a Direct Line

The CT/PET software only allows one AW to be configured via the GUI for Direct Connect over a direct line. If a site has multiple AW’s on a Direct Connect network (isolated from the hospital backbone), you may manually configure the additional AW's. You still need to configure the first AW via the GUI steps outlined inConfiguring the First AW for Direct Connect over a Direct Line to enable the Direct Connect feature.

  1. Open a command window.

  1. Login as root and enter the proper password:

    NOTE:If the Password has not been modified by the site and is not known, contact Local GE Service.

    1. su -

    1. Password:

  1. Type: cp /etc/exports{,.lfc}

  1. Type: echo "/usr/g/sdc_image_pool X.XX.XX.XX(async,ro)" >> /etc/exports

    1. Enter IP address of second Ethernet card of AW (eth1) in place of X.XX.XX.XX.

    1. For each additional network host, repeat Step 4 prior to proceeding to Step 5.

  1. Type: /etc/init.d/nfs restart

    NOTE:For information on how to set-up the CT/PET console as a Direct Connect remote host on the AW4.3, please refer to the AW4.3 Service Manual (5136311-100), Installation Job Cards List-Job Card IST 002. When configuring the remote host on the AW, the field “IP used for Direct Connect” should be completed with the “Console IP Address”, which you copied down in Configuring the First AW for Direct Connect over a Direct Line, Step 10.
