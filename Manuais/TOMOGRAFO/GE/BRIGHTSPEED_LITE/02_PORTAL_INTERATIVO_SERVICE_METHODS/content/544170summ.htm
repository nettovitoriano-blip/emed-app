2  Procedure

2.1   Over Hospital Backbone Connection Setup

A gigabit network is required to use Direct Connect over the hospital backbone. If you believe the hospital backbone is a gigabit network but the software will not enable you to configure Direct Connect over the network, check to see if a < 1 GB switch is pulling down the network speed to the system.

2.1.1  Configuring an AW IP Address for Direct Connect

  1. With Applications software up, select the [Service] icon to access the Common Service Desktop.

  1. Select the [Configuration] tab.

  1. Select [Configure AW Direct Connect].

  1. Enter AW IP address.

    (Step Details)

  1. Select [Accept].

  1. You will receive a message indicating that the AW IP address has been configured for Direct Connect. You will now be able to use Direct Connect with this AW.

    (Step Details)

  1. Select [Dismiss] to exit out of GUI.

2.1.2  Deleting an AW IP Address for Direct Connect

  1. Switch to the Service icon.

  1. Select the [Configuration] tab.

  1. Select [Configure AW Direct Connect].

  1. Enter AW IP address.

  1. Select [Delete].

  1. You may receive a message indicating that the AW IP address has been un-configured for Direct Connect.

  1. Select [Dismiss] to exit out of GUI.

    (Step Details)

2.2.2  Configuring Multiple AW’s for Direct Connect over a Direct Line

The CT/PET software only allows one AW to be configured via the GUI for Direct Connect over a direct line. If a site has multiple AW’s on a Direct Connect network (isolated from the hospital backbone), you may manually configure the additional AW's. You still need to configure the first AW via the GUI steps outlined inConfiguring the First AW for Direct Connect over a Direct Line to enable the Direct Connect feature.

  1. Open a command window.

  1. Login as root and enter the proper password:

    NOTE:If the Password has not been modified by the site and is not known, contact Local GE Service.

    1. su -

    1. Password:

  1. Type: cp /etc/exports{,.lfc}

  1. Type: echo "/usr/g/sdc_image_pool X.XX.XX.XX(async,ro)" >> /etc/exports

    1. Enter IP address of second Ethernet card of AW (eth1) in place of X.XX.XX.XX.

    1. For each additional network host, repeat Step 4 prior to proceeding to Step 5.

  1. Type: /etc/init.d/nfs restart

    (Step Details)
