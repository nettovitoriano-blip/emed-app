AW Direct Connect Pre-install Guide

Last Revised:17 February 2006

1  Purpose

The intent of this pre-install guide is to help ensure that the field engineer has gathered all information from the customer to the complete the installation and configuration of AW Direct Connect on a CT scanner.

2  Feature Summary

Direct Connect allows the user to utilize the AW to process images on the CT console, without having to first pull them to the AW. Source images remain on the CT console, while new post-processed images are saved to the AW.

3  Prerequisites

The AW Direct Connect feature requires the following AW hardware and software:

  • AW HP xw8000 or HP xw8200 computer

  • AW Software Release AW 4.3 software (AW4.3_03A.07_EXT), or more recent

  • CT Host Console Software Release 06MW03.x, or more recent

4  Required Information

  • Are the hardware and software prerequisites, listed above, satisfied?

  • Will the AW be directly connected to the CT scanner host console via a crossover cable, or will it be connect to the CT scanner host console via the hospital network/backbone?

  • If the AW is to be connected to the CT scanner host console via the hospital backbone, does the hospital have a gigabit (1000 Mb/s) network?

    This can be determined by performing the following steps on the console:

    1. Log in as root:

      1. Type su -

      2. Type #bigguy

    2. If using an HP xw8200 computer as the AW, type ethtool eth0 | grep Speed

    3. If using an HP xw8000 computer as the AW, type ethtool eth0 | grep Speed

      Output should be either:

      • Speed: 1000 Mb/s (gigabit network)

      • Speed: 100 Mb/s (non-gigabit network)

5  Actions Required

If the hospital has a gigabit network (1000 Mb/s), they can perform Direct Connect over the hospital backbone. No further actions are necessary prior to installation.

If the hospital does not have a gigabit network (1000 Mb/s), they will be unable to configure Direct Connect over the hospital network.

The hospital will need to create a connection isolated from the hospital network by physically running a cable from the CT host console to the AW. This needs to be done prior to software installation in order for the customer to utilize the Direct Connect feature.

NOTE:The direct connect network cable must connect the “AW/X” port on the CT host console to the “eth1” port on the AW.

For more detailed instructions on creating a Direct Connect network, please refer to the AW4.3 Service Manual (5136311-100), Chapter 1, Section 2 (Installation Guide).
