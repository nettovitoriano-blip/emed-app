2  Overview

This procedure describes the replacement of the GOC4 Operator Console Image Generator (IG) Node(s).

  • Verify that the DARC Node is able to access a remote shell successfully.

  • Perform initialization of each IG Node (repower sequence).

  • Perform diagnostics for the IG Node RAC(s).

  • Start up the application software and verify that image_generation is running for each IG Node.

  • Halt the process, then repower the Operator Console and bring it up to Application software to make sure image_generation is running.

  • Perform a Recon Data Path test.

  • Perform sanity scans (e.g., scout, axial & helical).

NOTE:Whenever a Jarrell type IG Node is used, it MUST be placed in the bottom standard slot 1 position. The Ethernet cable identifying the bottom IG #1 must be correctly connected between the DARC Node and the IG Node. If two Jarrell IG Nodes are present, the second Jarrell IG Node must be placed in slot 2 (middle).

NOTE:Jarrell DARC and Jarrell IG Nodes require software release 06MW29.7 or more recent.

NOTE:SDAS 4-slice, MDAS and GDAS 4-slice and 8-slice systems cannot upgrade from the 1 single/standard IG Node to the 3 IG Node upgrade option.

4  Procedure

4.1  Power-Off (Shut Down) the Console

  1. Select one of the following methods to Power OFF the Operator Console:

    1. If Applications are up, click on the [Shut Down] icon and select [Shutdown].

    NOTICE
    (For 06MW03.X Software) Wait 1-2 minutes after the “System halted” message appears, to allow the DARC Node to properly power-down. SW release 06MW29.7 has corrected this issue.
     

    1. If Applications are down, open a Unix Shell at the Toolchest. Type:

      {ctuser@hostname}:  halt

    The Operator Console monitor will display a 'System halted' message when it is acceptable to power OFF the Operator Console.

  1. Power OFF the Operator Console at the front panel switch.

4.2  Remove the Old IG Node

  1. Remove the front and rear Operator Console covers.

  1. Remove the rear Ethernet cable connection(s) to the specific IG Node(s) being replaced. If more than one cable is being disconnected, verify each cable is present and clearly marked; if necessary, add a label for clarity.

  1. Remove the power cord at the rear panel of the specific IG Node(s) being replaced.

  1. Remove and retain the two (2) front mounting screws, and slide out the specific IG Node(s) being replaced.

4.3  Install the Replacement IG Node

NOTE:Whenever a Jarrell type IG Node is used, it MUST be placed in the bottom standard slot 1 position. The Ethernet cable identifying the bottom IG #1 must be correctly connected between the DARC Node and the IG Node. If two Jarrell IG Nodes are present, the second Jarrell IG Node must be placed in slot 2 (middle).

NOTE:Jarrell DARC and Jarrell IG Nodes require software release 06MW29.7 or more recent.

  1. Slide the replacement (or repositioned) IG Node(s) into the Operator Console, from the front. The bottom slot is the standard slot reserved for IG Node #1 (see Note above). IG Node #2 is positioned directly above IG Node #1. IG Node #3 is positioned directly above IG Node #2.

  1. Replace the two (2) front mounting screws on the front of the replaced or repositioned IG Node(s).

  1. Verify the power switch (located at the rear of the IG Node, if present) is set to the ON position.

  1. Replace the rear Ethernet cable(s) between the DARC2 Node and the replaced or repositioned IG Node(s).

    NOTE:A Jarrell version of the DARC2 Node will be a valid replacement part for GOC4 Operator Consoles in the future.

4.4  Power-ON the Operator Console

  1. Power ON the Operator Console at the front switch.

  1. At the DARC2 Node, verify the rear power switch (if present) is set to the ON position.

  1. Visually verify the DARC2 Node front panel Power LED is illuminated. If not, press the front panel power switch (hold 3-10 seconds) to apply power to the DARC2 Node.

  1. At each replaced or repositioned IG Node:

    1. Verify the power cord is plugged in.

    1. Verify the Ethernet cable is properly connected.

    1. Verify the rear panel power switch is ON (if present).

  1. Visually verify each replaced or repositioned IG Node front panel LED is illuminated. If not, press the front panel power switch(es) (hold 3-10 seconds) to apply power to the IG Node(s).

  1. Stop Applications from auto-starting at the 5 second PINK Box.

4.5  Verify DARC2 Node is Up

The DARC2 Node must be up to check the IG Node(s). Perform ping and rsh commands on the DARC2 Node, as follows:

  1. At the Toolchest, with Application software down, open a Unix Shell.

  1. Ping the DARC2 Node:

    {ctuser@hostname}  ping  darc

    Verify ping is successful.

    Press <Ctrl+C> to stop ping process.

  1. Remote Shell to the DARC2 Node:

    {ctuser@hostname}  rsh  darc

    Verify ctuser@darc prompt is present.

  1. Exit from the DARC2 Node Remote Shell:

    ctuser@darc  exit

    NOTE:This Unix Shell will be used again, so do not exit or close, at this time.

4.6  Initialize IG Node Communications and Run Diag - Required

In some configurations, the GOC4 Operator Console may have up to three (3) IG Nodes. In the instructions below, be certain to specify ig1, ig2 or ig3, as appropriate for the IG Node(s) being tested.

NOTE:Application Software must be down.

  1. Power OFF the replaced or repositioned IG Node(s) at the front panel switch.

    See Illustration 6, for switch location.

    Illustration 6:  Westville IG Node #2362872

    Illustration 7:  ”Jarrell” IG Node #5147443

  1. Power ON the replaced or repositioned IG Node at the front panel switch (hold for 3-10 seconds).

  1. Wait two to four minutes for the IG Node to boot up.

    NOTE:Whenever an IG Node is swapped (either the physical location or one end of the Ethernet cable), the affected IG Node requires a manual power cycle at the front panel. This manual power cycle is required for the IG Node to get an IP address and configuration information.

  1. In the Unix Shell, verify the cat /usr/g/config/INFO file for number of IGs (NUMIG) actively configured in the Operator Console.

    NOTE:If the number of IG Nodes present is incorrect, then refer to Reconfig Note.

    {ctuser@hostname}  cat /usr/g/config/INFO

  1. In the Unix Shell, verify the following IG Node(s) as applicable:

    NOTE:For an Ethernet cabling connection issue, use the command ‘ethtool -p eth#’ (where # represents the Ethernet address) as root on the DARC2 Node or IG Node to determine if the Ethernet cable is correctly connected from the DARC2 Node to the IG Node. The port will blink or flash when activated and <Ctrl+C> will stop the test. This command can be used on the Host, DARC2 Node and the IG Node(s).

    Example for IG Node #1 Ethernet cable:

    [root@ig1] ethtool -p eth0   (<Ctrl+C> to stop the flashing Ethernet port LED)

    {ctuser@hostname}  rsh darc

    {ctuser@darc}  su -

    Password:  #<password>

    [root@darc]  rsh ig1

    [root@ig1]  exit

    [root@darc]  rsh ig2

    [root@ig2]  exit

    [root@darc]  rsh ig3

    [root@ig3]  exit

    [root@darc]  exit

    {ctuser@darc}  exit

    {ctuser@hostname}  cd  /usr/g/bin

    {ctuser@hostname}  ls  rac*

    (racdiags* are listed)

    NOTE:The racdiags command performs IG Node Recon Accelerator Card (rac) diagnostics for all IG Nodes configured in the system from a Unix Shell on the Host Computer. Ignore any errors associated with IG Nodes not configured in the Operator Console. The racdiags 1 command performs rac diagnostics for a single IG #1 Node.

    {ctuser@hostname}  racdiags  - or -  racdiags  1  (See NOTE)

4.7  Start Application Software/Image Generation - Required

  1. In the Unix Shell, start Application software:

    {ctuser@hostname}st

  1. When Application software is up, open a Unix Shell to check image_generation for each IG Node present and configured in the console:

    {ctuser@ig#} or [root@ig#]ps -leaf|grep -v grep|grep image_generation

    4 S ctuser 767 766 0 81 0 - 1143rt_sig 14:52? 00:00:00csh -c image_generation -bp

    0 -host darc -node 1 -rac 0

    0 S ctuser 785 767 0 75 0 - 48692- 14:52? 00:00:00 image_generation -bp 0 -ho st

    darc-node 1 -rac 0

  1. Verify two lines are returned for each IG Node.

  1. Exit out of each IG Node:

    {ctuser@ig#} or [root@ig#] exit

4.8  Halt - Required

After an IG Node is replaced or repositioned (cables swapped) the IG Node must be powered off and then on again so it can initialize. To check if the initialization worked properly, halt the Console. If the IG Node does not come up properly under DARC control, perform the initialization process again.

  1. In the Unix Shell, shutdown Application software:

    {ctuser@hostname}: cleanMon

  1. Once Applications are down, open a Unix Shell at the Toolchest:

    {ctuser@hostname}: halt

  1. The Operator Console monitor displays System halted when it is acceptable to power OFF the Operator Console.

  1. Power OFF the Operator Console at the front panel switch.

  1. Wait 30 seconds to 1 minute for drives to settle.

  1. Power ON the Operator Console at the front panel switch.

  1. In the Unix Shell, start Application software:

    {ctuser@hostname} st

  1. When Application software is up, open a Unix Shell to check image_generation for each IG Node present and configured in the console:

    {ctuser@ig#} or [root@ig#]ps -leaf|grep -v grep|grep image_generation

    4 S ctuser 767 766 0 81 0 - 1143rt_sig 14:52? 00:00:00csh -c image_generation -bp

    0 -host darc -node 1 -rac 0

    0 S ctuser 785 767 0 75 0 - 48692- 14:52? 00:00:00 image_generation -bp 0 -ho st

    darc -node 1 -rac 0

  1. Verify two lines are returned for each IG Node.

  1. Exit out of each IG Node:

    {ctuser@ig#} or[root@ig#] exit

  1. Close the Unix Shell.

4.9  Verify Recon Data Path Diagnostic

  1. Select the Service Icon.

  1. Select [DIAGNOSTICS].

  1. Select [Recon Data Path].

  1. Select [1] and [ALL]

  1. Select [RUN]

  1. Verify Recon Data Path tests pass.

  1. Select [Dismiss].

5  Finalization

  1. Perform sanity scans (e.g., scout, axial & helical).

    Verify the image(s) reconstruct and are displayed.

  1. Install the front and rear Operator Console covers.
