Scan TypeAxialIn a Axial mode, there are several options relative to scanning and displaying images, either 4 x i, or 2 x I (where i = thickness)
In a 4 x i mode, images are created from the rows used as indicated by slice thickness. This mode should always be used to troubleshoot Detector / DAS related artifacts.
In a 2 x i mode Recon actually combines 2 rows of data to produce a thicker slice.
Scan TypeHelicalImages are created using data from all Rows used during data acquisition. (The actual rows being dependent on slice thickness) The amount of data used to reconstruct a image from a row, or row weighting is dependent on table speed.
