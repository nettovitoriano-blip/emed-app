Reconfig Note

If the number of IG Nodes present is incorrect, then perform the reconfig process as root on the Host with Application Software down.

{ctuser@hostname}  su -

Password:  #bigguy

[ctuser@root]  reconfig

Select the Hardware Tab

Correct for the number of IG Nodes actually present in the Operator Console.

Select Accept Tab

The Operator Console will reboot
