3  Preliminary Requirements

3.1  Safety

NOTICE
To prevent damage to components within the HP xw8x00 chassis, observe the following ESD precautions:

  • Work on a static-free mat.

  • Wear a static strap to ensure that any accumulated electrostatic charge is discharged from your body to ground.

  • Create a common ground for the equipment you are working on by connecting the static-free mat, static strap and peripheral units to that piece of equipment.

 

4  Procedure

4.1  Remove the Side Cover

With ALL cables removed from the old and new Host Computers, perform the following steps:

  1. Unlock the cover on the side of the old Host Computer.

    The cover keys are attached to the back panel of the system.

  1. Pull out on the side cover latch to release the side cover.

  1. Tilt the cover open, then lift it off. Refer to Illustration 1.

    Illustration 1:  Opening the Side Cover

  1. Repeat the above procedure, to open the new Host Computer.

4.2  Swapping Network Interface Cards

The Customer Options Keys are tied to the master Network Interface Card (NIC) unique MAC address (always eth0) and must be swapped into the new computer. Failure to do this will result in the need to regenerate the Customer keys to reactivate their specific options. The hostid command (as root on host) provides the hex equivalent of the eth0 HW Address (ifconfig eth0 command).

NOTE:The NIC swap process must not be performed on systems experiencing communication issues associated with the master NIC (either port).

  1. Determine the master NIC using Table 1. This must be determined for both the old computer and the new computer.

    Table 1:  Host Ethernet Address Chart

    Physical PortNamexw8000xw8200
    AHSPeth0 (master hostid)eth2
    BG1 (STC)eth1eth3
    CDARCeth2eth0 (master hostid)
    DG2 (TGP)eth3eth1

  1. Remove the master Network Interface Card from the old computer and install it in the appropriate slot position (A/B or C/D) in the new Host Computer.

    Table 2:  Master NIC Placement

    Original HostMaster NICReplacement HostNIC Placement

    xw8000A/Bxw8200C/D
    xw8200C/Dxw8200C/D
    xw8200C/Dxw8000A/B

  1. For All-In-One console (Console without DARC), xw8400 is used. Below is the NIC port description of xw8400:

    Table 3:  AIO Host Ethernet Address Chart

    Physical PortNamexw8400
    A (Right upper port) HSPeth2
    B (Right low port)G1 (STC)eth3
    C (Left Upper port)IG1eth0 (master hostid)
    D (Left low port)G2 (TGP)eth1
    NOTE:xw8400 can’t be replaced by xw8000 or xw8200. In the meantime, we can’t replace xw8000/xw8200 with xw8400.

  1. Insert the unused Network Interface Card (from new computer) into the computer you are returning. The computer MUST be returned with both NICs installed.

4.3  Replace the Side Cover

  1. Ensure that all internal cables are properly connected and safely routed in the new Host Computer.

  1. Place the side cover onto the Host Computer chassis (aligning the guide rail on the bottom inside edge of the cover with the bottom edge of the Host Computer chassis). Refer to Illustration 2.

    Illustration 2:  Aligning and Closing the Cover

  1. Verify no cables are pinched, and gently close the cover.

  1. Lock the cover using the key provided.

  1. Repeat the above procedure, to close and lock the original Host Computer, with the new drives installed.

NOTE:A Reconfig is required when the console is powered on.
