INSTALLING THE ACROBAT READER with SEARCH

The Acrobat Reader 4.0 or above is required to view some of the documentation on this CD. To install the US version of Acrobat Reader in your computer, use this CD-ROM and follow the instructions described  below.
If your computer has already a previous version of Acrobat Reader, please uninstall it first, before installing the new version.

Windows 95/NT/2000:

Download the newest version of Acrobat Reader from the Adobe Acrobat Home Page, or install the Acrobat 4.0 Reader from this CD-ROM, as follows:

1. Go to directory "\Acrobat\Windows95_98_NT" on this CD-ROM in the Windows Explorer.

2. Double-click the rs40eng.exe if you want install Acrobat Reader 4.0 or go to the Adobe Acrobat Home Page if you want install the latest version of Acrobat Reader.

3. Follow the instructions on your screen.

4. After finished the installation, start the Acrobat Reader and minimize it.

5. If you need to display PDF files with Chinese, Japanese or Korean embeded fonts for purposes other than this CD-ROM, perform the installation of Asian Font Pack. If not, click here to enter the Main Menu of this CD ROM.


Note for this version:

If there is a failure at any point during the installation of Acrobat Reader 4.0, the installer performs a complete uninstall. For this reason, it is important not to close the installer application by clicking its close box in the upper right corner of the background window after clicking the "Thank You" dialog that appears at the end of the installation. If you wait for a second or two, the installer will automatically close the background windows after the installation is complete.

For more information about the Acrobat Reader, or to download Acrobat Reader for Windows or UNIX, visit the Adobe Acrobat Home Page at : http://www.adobe.com/prodindex/acrobat/readstep.html

This CD-ROM does not necessarily require Asian Fonts to display PDF Service Documents.


Tips:

  • To display small characters legibly in a PDF file, not as gray lines:
    From your Reader 4.x/5.x menu bar, choose File => Preferences => General. Then uncheck or decrease the number of Pixels in the [Use Greek Text Below:] check box. Click here to display a sample of General window.
  • To display Acrobat documents in a separate Acrobat viewer window uncheck the [Web Browser Integration] check box.
  • To load the Reader Search index, click [Search] icon button => Indexes => Add then open [CDROM Drive]:\Index.pdx file.
  • Configuring Internet Explorer to display PDF Files:
    Check the Adobe Acrobat Technical Documentation: http://www.adobe.com/support/techdocs/98fe.htm
