
Please, read the following before running this GEYMS CT Service Documentation CDROM:


FOR V/R5.5 OR LATER, TO EJECT THIS CDROM FROM OPERATOR CONSOLE ENTER "eject" FROM THE SHELL WINDOW. 


MINIMUM HARDWARE AND SOFTWARE REQUIREMENT

This GEYMS CT Service Documentation CDROM contains PDF files with large size (some with more than 30MB).
Before running this CDROM, check the minimum requirements below.

1. Pentium 200MHz (or equivalent processor) or more;
2. 64MB RAM or more;
3. 120MB free hard disk space and enough virtual memory space;
4. 12X CD ROM Drive or more;
5. 800x600 pixels, 16bit color minimum graphics resolution or better;
6. Windows 95, Windows NT 3.51 or higher;
7. Internet Explorer 4.01 or Netscape Navigator 4.04 or later;
8. Acrobat Reader with Search 4.0 or later (see Installation procedure below).

Note: Close other applications before opening big pdf files.


INSTALLATION PROCEDURE FOR ACROBAT READER 4.0 FOR WINDOWS WITH SEARCH AND JAPANESE/CHINESE/KOREAN FONT

1. Download rs40eng.exe (6.3MB) to your local temporary directory.
2. Install it, following the messages during the installation. If you already have a Reader 3.xx in your computer 
   and want to keep it to use both versions, install the Reader 4.0 in a new directory. But remember that if ou uninstall
   the 3.xx, you must reinstall 4.0 again.

Installing the Japanese Font
3. After installing the Reader 4.0 English version, download and execute the jpnfont.exe file 
   (Japanese Support Language Font) at ftp://3.36.10.5/Acrobat/Reader40+Search+Asian_Fonts/JapaneseFont/jpnfont.exe (5.6MB). 

   For Chinese or Korean fonts, download the corresponding language font at
      ftp://3.36.10.5/Acrobat/Reader40+Search+Asian_Fonts/ChineseFont/chtfont.exe (10.9MB) or
      ftp://3.36.10.5/Acrobat/Reader40+Search+Asian_Fonts/KoreanFont/korfont.exe (8.3MB)

4. Delete or take a backup of rs40eng.exe from your local temporary directory.


TO REMOVE THIS CDROM FROM OPERATOR CONSOLE

1. Start Shell
2. Type "eject"
3. Press ENTER key.

TO TERMINATE THE SERVICE DESKTOP PROCESS
1. Star Shell
2. Type "ps -ef |grep service"
3. Note the service_browser process number
3. Press ENTER key
4. Type "kill" and space key and then the service_browser process number shown in the shell window
5. Press ENTER key
6. Restart SV Desktop
